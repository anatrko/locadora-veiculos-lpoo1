Tecnologias:

Java 21
NetBeans 32
Maven
Git e GitHub

Como acessar o projeto:

1. Instale o Java 21, NetBeans e Git.
2. Abra o NetBeans.
4. Vá em Team → Git → Clone
Cole o link:
https://github.com/anatrko/locadora-veiculos-lpoo1.git (link do repositório)
5. Selecione a branch main e finalize.
6. Abra o projeto LocadoraVeiculos

Para trabalhar no projeto:
Antes de começar: faça Pull
Depois de programar: faça Commit
Para enviar suas alterações: faça Push

Sempre avisem o grupo antes de mexer em arquivos que outra pessoa esteja desenvolvendo!!!!!!!!!!!!!
